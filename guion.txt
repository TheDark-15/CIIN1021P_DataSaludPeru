========================

- 6 archivos SQL (scripts para SQL Server)
  - Crear la base de datos
  - Crear las tablas
  - Procedimientos para meter los datos
  - Triggers para auditoría
  - Roles y seguridad
  - Backup y restore

- análisis de problemas de calidad

- .gitignore (para que Git ignore los datos sensibles)

"Hicimos un análisis de los datos del MINSA. Creamos la base de datos 
DataSaludPerú con tablas para atenciones y afiliados. Identificamos

- Crear BD con esquemas separate (prod, audit, dw)
